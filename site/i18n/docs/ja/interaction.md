# ジェスチャーとキーボード

入力はチャート自身が処理します。バインディングはプラットフォームのイベントを`InputEvent`に変換するだけです（`ferrochart-winit`と`ferrochart-wasm`がこれを代わりに行います）。

## ジェスチャー

| 入力 | 効果 |
|---|---|
| プロット内でドラッグ | パン（動かしながら離すと慣性スクロール） |
| ホイール／トラックパッドのスクロール | ポインターを中心に時間方向にズーム。横スクロールまたはShift+ホイールでパン |
| 価格軸上でホイール、またはAlt+ホイール | 価格方向にズーム |
| ピンチ（トラックパッド、2本指） | ズーム |
| 価格軸をドラッグ | 価格のスケールを変更（自動スケールがオフになります） |
| 時間軸をドラッグ | 足の間隔を変更 |
| 軸をダブルクリック | リセット（自動スケール、デフォルトの間隔） |
| ← → / ↑ ↓ | 10 % パン / ズーム |
| Home / End | 最初／最新の足へジャンプ |

クロスヘアはポインターに追従し、軸には価格と時刻のラベルが表示されます。モードは`Normal`、`Magnet`（その足の始値・高値・安値・終値のうち最も近い値にスナップ）、`Hidden`のいずれかです。

## タッチ操作

タッチスクリーン（スマートフォン、タブレット、タッチ対応ノートPC）では指をホバーできないため、マウスとはジェスチャーが異なります。ペンはマウスと同じように動作します。

| タッチ操作 | 効果 |
|---|---|
| 1本指でドラッグ | パン（動かしながら離すと慣性スクロール） |
| 2本指 | 指の間隔の変化に応じて中点を中心に時間方向にズームし、中点の移動に合わせてパン。片方の指を離しても、もう片方の指でパンを続けられます |
| 1本指を500 ms動かさずに押し続ける | クロスヘアを表示。パンせずに指に追従し、指を離しても表示が残ります |
| タップ | クリック。長押しで残ったクロスヘアも非表示にします |
| 軸をダブルタップ | ダブルクリックと同じようにリセット |

- 押下がドラッグに変わるには、指が8 CSS px動く必要があります（マウスでは3 px）。そのため、少し指がぶれてもタップはクリックになります。
- 指はより遠くからでも対象にヒットします。ラインから10 CSS px、描画のハンドルから12 px、マーカーの外側8 pxまでです。
- 描画の作成中やドラッグ中は、2本目の指は無視されます。
- クロスヘアのモードが`Hidden`の場合、指を動かさずに押し続けても特別な動作はありません。指を動かすとパンします。
- システムがタッチ操作を引き継ぐと（ページのスクロール開始や着信など）、クリックや慣性スクロールを起こさずにジェスチャーが終了します。

ブラウザーでは、縦スワイプでチャートをパンするかページをスクロールするかを`touchScroll`オプションで設定します。[タッチスクリーン](web.md#touch-screens)を参照してください。

## イベント

チャートが通知する内容（クロスヘアの移動、クリック、表示範囲の変化、過去データの要求、描画の変更）は[クロスヘアとイベント](crosshair-events.md)で説明しています。Rustでは`Chart::drain_events`で同じイベントを取り出します。しばらく取り出さずにいると、新しいクロスヘアと範囲のイベントが古いものを置き換え、溜まり続けることはありません。

## 時刻

入力イベントはタイムスタンプ（`time_ms`）を持ち、`build_frame`は現在時刻（`now_ms`）を受け取ります。両方とも同じ時計から取得する必要があります。慣性スクロールと長押しはこれらを使います。イベント時刻またはフレーム時刻が押下から500 msに達すると、動かさずに押し続けている指の位置にクロスヘアが表示されます。バインディングは`performance.now()`（Web）、またはウィンドウとともに開始する単調増加の時計（デスクトップ）を使います。
