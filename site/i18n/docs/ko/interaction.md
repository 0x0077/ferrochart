# 제스처와 키보드

차트는 입력을 스스로 처리하며, 바인딩은 플랫폼 이벤트를 `InputEvent`로 변환하기만
합니다(`ferrochart-winit`과 `ferrochart-wasm`이 이를 대신 해 줍니다).

## 제스처

| 입력 | 효과 |
|---|---|
| 플롯에서 드래그 | 이동(움직이는 중에 놓으면 관성 스크롤) |
| 휠 / 트랙패드 스크롤 | 포인터를 중심으로 시간 확대·축소, 가로 스크롤 또는 Shift+휠은 이동 |
| 가격 축 위에서 휠, 또는 Alt+휠 | 가격 확대·축소 |
| 핀치(트랙패드, 두 손가락) | 확대·축소 |
| 가격 축 드래그 | 가격 스케일 조정(자동 스케일 꺼짐) |
| 시간 축 드래그 | 봉 간격 변경 |
| 축 더블클릭 | 초기화(자동 스케일, 기본 간격) |
| ← → / ↑ ↓ | 10 %씩 이동 / 확대·축소 |
| Home / End | 첫 번째 / 최신 봉으로 이동 |

크로스헤어는 포인터를 따라가며 축에 가격과 시간 레이블을 표시합니다. 모드는
`Normal`, `Magnet`(봉의 시가, 고가, 저가, 종가 중 가장 가까운 값에 맞춤),
`Hidden` 중 하나입니다.

## 터치

터치스크린(휴대폰, 태블릿, 터치 노트북)에서는 손가락으로 호버할 수 없으므로
마우스와 제스처가 다릅니다. 펜은 마우스처럼 동작합니다.

| 터치 | 효과 |
|---|---|
| 한 손가락으로 드래그 | 이동(움직이는 중에 떼면 관성 스크롤) |
| 두 손가락 | 두 손가락 사이 거리의 변화에 따라 중점을 중심으로 시간을 확대·축소하고, 중점과 함께 이동. 한 손가락을 떼어도 다른 손가락으로 계속 이동 |
| 한 손가락을 500 ms 동안 움직이지 않고 누르기 | 크로스헤어 표시. 이동하지 않고 손가락을 따라가며, 손가락을 떼어도 유지됨 |
| 탭 | 클릭. 길게 눌러 남아 있던 크로스헤어도 숨김 |
| 축을 두 번 탭 | 더블클릭처럼 초기화 |

- 누르기가 드래그로 바뀌려면 손가락이 8 CSS px 움직여야 합니다(마우스는 3 px).
  따라서 조금 흔들리는 탭도 클릭으로 처리됩니다.
- 손가락은 더 먼 거리에서도 대상을 누를 수 있습니다. 선에서는 10 CSS px,
  드로잉 핸들에서는 12 px, 마커 밖에서는 8 px까지입니다.
- 드로잉을 그리거나 드래그하는 동안에는 두 번째 손가락을 무시합니다.
- 크로스헤어 모드가 `Hidden`이면 손가락을 가만히 눌러도 특별한 동작은 없으며,
  움직이면 이동합니다.
- 시스템이 터치를 넘겨받으면(페이지 스크롤이 시작되거나 전화가 걸려 오면)
  클릭이나 관성 스크롤 없이 제스처가 끝납니다.

브라우저에서 세로 스와이프가 차트를 이동할지 페이지를 스크롤할지는 `touchScroll`
옵션으로 정합니다. [터치스크린](web.md#touch-screens)을 참고하세요.

## 이벤트

차트가 보고하는 내용(크로스헤어 이동, 클릭, 표시 범위 변경, 과거 데이터 요청,
드로잉 변경)은 [크로스헤어와 이벤트](crosshair-events.md)에 설명되어 있습니다.
Rust에서는 `Chart::drain_events`로 같은 이벤트를 가져옵니다. 한동안 가져가지
않으면, 새로운 크로스헤어 이벤트와 범위 이벤트가 쌓이지 않고 이전 이벤트를
대체합니다.

## 시간

입력 이벤트는 타임스탬프(`time_ms`)를 담고, `build_frame`은 현재 시간
(`now_ms`)을 받습니다. 둘은 같은 시계에서 와야 합니다. 관성 스크롤과 길게
누르기가 이 값들을 사용합니다. 손가락을 가만히 누른 채 이벤트 시간이나 프레임
시간이 누른 시점에서 500 ms에 도달하면 크로스헤어로 바뀝니다. 바인딩은
`performance.now()`(웹) 또는 창과 함께 시작된 단조 시계(데스크톱)를 사용합니다.
