# 제스처와 키보드

차트는 입력을 스스로 처리하며, 바인딩은 플랫폼 이벤트를 `InputEvent`로 변환하기만
합니다(`ferrochart-winit`과 `ferrochart-wasm`이 이를 대신 해 줍니다).

## 제스처

| 입력 | 효과 |
|---|---|
| 플롯에서 드래그 | 이동(움직이는 중에 놓으면 관성 스크롤) |
| 휠 / 트랙패드 스크롤 | 포인터를 중심으로 시간 확대·축소, 가로 스크롤 또는 Shift+휠은 이동 |
| 가격 축 위에서 휠, 또는 Alt+휠 | 가격 확대·축소 |
| 핀치(트랙패드, 터치) | 확대·축소 |
| 가격 축 드래그 | 가격 스케일 조정(자동 스케일 꺼짐) |
| 시간 축 드래그 | 봉 간격 변경 |
| 축 더블클릭 | 초기화(자동 스케일, 기본 간격) |
| ← → / ↑ ↓ | 10 %씩 이동 / 확대·축소 |
| Home / End | 첫 번째 / 최신 봉으로 이동 |

크로스헤어는 포인터를 따라가며 축에 가격과 시간 레이블을 표시합니다. 모드는
`Normal`, `Magnet`(봉의 시가, 고가, 저가, 종가 중 가장 가까운 값에 맞춤),
`Hidden` 중 하나입니다.

## 이벤트

차트가 보고하는 내용(크로스헤어 이동, 클릭, 표시 범위 변경, 과거 데이터 요청,
드로잉 변경)은 [크로스헤어와 이벤트](crosshair-events.md)에 설명되어 있습니다.
Rust에서는 `Chart::drain_events`로 같은 이벤트를 가져옵니다. 한동안 가져가지
않으면, 새로운 크로스헤어 이벤트와 범위 이벤트가 쌓이지 않고 이전 이벤트를
대체합니다.

## 시간

입력 이벤트는 타임스탬프(`time_ms`)를 담고, `build_frame`은 현재 시간
(`now_ms`)을 받습니다. 둘은 같은 시계에서 와야 합니다. 관성 스크롤이 이 값들을
사용합니다. 바인딩은 `performance.now()`(웹) 또는 창과 함께 시작된 단조
시계(데스크톱)를 사용합니다.
