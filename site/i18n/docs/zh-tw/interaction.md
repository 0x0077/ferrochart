# 手勢與鍵盤

圖表自行處理輸入；綁定只負責把平台事件轉換成 `InputEvent`（`ferrochart-winit` 與 `ferrochart-wasm` 已經替你做好）。

## 手勢

| 輸入 | 效果 |
|---|---|
| 在繪圖區拖曳 | 平移（移動中放開：慣性捲動） |
| 滾輪／觸控板捲動 | 以指標為中心縮放時間；水平捲動或 Shift+滾輪則平移 |
| 在價格軸上滾動滾輪，或 Alt+滾輪 | 縮放價格 |
| 雙指縮放（觸控板、觸控） | 縮放 |
| 拖曳價格軸 | 縮放價格刻度（關閉自動縮放） |
| 拖曳時間軸 | 改變 K 棒間距 |
| 雙擊座標軸 | 重設該座標軸（自動縮放、預設間距） |
| ← → / ↑ ↓ | 平移 10 %／縮放 |
| Home / End | 跳到第一根／最新的 K 棒 |

十字游標跟隨指標，並在座標軸上顯示價格與時間標籤。其模式為 `Normal`、`Magnet`（吸附到該 K 棒開、高、低、收中最接近的一個）或 `Hidden`。

## 事件

圖表回報的內容（十字游標移動、點擊、可見範圍變更、歷史資料請求、繪圖變更）請參見[十字游標與事件](crosshair-events.md)。在 Rust 中，以 `Chart::drain_events` 取出相同的事件；若一段時間沒有取出，較新的十字游標與範圍事件會取代較舊的，而不會不斷累積。

## 時間

輸入事件攜帶時間戳記（`time_ms`），`build_frame` 則接受目前時間（`now_ms`）；兩者必須來自同一個時鐘。慣性捲動會用到它們。綁定使用 `performance.now()`（Web）或隨視窗啟動的單調時鐘（桌面）。
