# 手勢與鍵盤

圖表自行處理輸入；綁定只負責把平台事件轉換成 `InputEvent`（`ferrochart-winit` 與 `ferrochart-wasm` 已經替你做好）。

## 手勢

| 輸入 | 效果 |
|---|---|
| 在繪圖區拖曳 | 平移（移動中放開：慣性捲動） |
| 滾輪／觸控板捲動 | 以指標為中心縮放時間；水平捲動或 Shift+滾輪則平移 |
| 在價格軸上滾動滾輪，或 Alt+滾輪 | 縮放價格 |
| 雙指縮放（觸控板、雙指） | 縮放 |
| 拖曳價格軸 | 縮放價格刻度（關閉自動縮放） |
| 拖曳時間軸 | 改變 K 棒間距 |
| 雙擊座標軸 | 重設該座標軸（自動縮放、預設間距） |
| ← → / ↑ ↓ | 平移 10 %／縮放 |
| Home / End | 跳到第一根／最新的 K 棒 |

十字游標跟隨指標，並在座標軸上顯示價格與時間標籤。其模式為 `Normal`、`Magnet`（吸附到該 K 棒開、高、低、收中最接近的一個）或 `Hidden`。

## 觸控

在觸控螢幕（手機、平板、觸控筆電）上，手指沒有懸停狀態，因此手勢與滑鼠不同。觸控筆的行為則與滑鼠相同。

| 觸控 | 效果 |
|---|---|
| 單指拖曳 | 平移（移動中抬起：慣性捲動） |
| 雙指 | 依兩指距離的變化，以中點為中心縮放時間，並隨中點移動平移；抬起一指後，另一指可繼續平移 |
| 單指按住不動 500 ms | 顯示十字游標；游標跟隨手指移動而不平移圖表，抬起後仍保留 |
| 輕觸 | 觸發點擊；也會隱藏長按後保留的十字游標 |
| 連點座標軸兩次 | 重設座標軸，與滑鼠雙擊相同 |

- 手指必須移動 8 CSS px，按壓才會變成拖曳（滑鼠為 3 px），因此稍有晃動的輕觸仍視為點擊。
- 手指的命中範圍較大：距離線條 10 CSS px、繪圖控制點 12 px，以及標記外緣以外 8 px。
- 正在繪製或拖曳繪圖時，會忽略第二根手指。
- 十字游標模式為 `Hidden` 時，按住不動不會觸發特殊行為；移動手指會平移圖表。
- 當系統接管觸控（頁面開始捲動、來電）時，手勢會結束，不會觸發點擊或慣性捲動。

在瀏覽器中，垂直滑動要平移圖表還是捲動頁面，由 `touchScroll` 選項決定；參見[觸控螢幕](web.md#touch-screens)。

## 事件

圖表回報的內容（十字游標移動、點擊、可見範圍變更、歷史資料請求、繪圖變更）請參見[十字游標與事件](crosshair-events.md)。在 Rust 中，以 `Chart::drain_events` 取出相同的事件；若一段時間沒有取出，較新的十字游標與範圍事件會取代較舊的，而不會不斷累積。

## 時間

輸入事件攜帶時間戳記（`time_ms`），`build_frame` 則接受目前時間（`now_ms`）；兩者必須來自同一個時鐘。慣性捲動和長按都會用到它們：當事件時間或影格時間達到按下後的 500 ms 時，按住不動的手指就會啟動十字游標。綁定使用 `performance.now()`（Web）或隨視窗啟動的單調時鐘（桌面）。
