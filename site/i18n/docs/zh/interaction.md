# 手势与键盘

图表自行处理输入；绑定层只需把平台事件转换为 `InputEvent`（`ferrochart-winit` 和 `ferrochart-wasm` 已经替你做好了）。

## 手势

| 输入 | 效果 |
|---|---|
| 在绘图区内拖动 | 平移（移动中松开：惯性滚动） |
| 滚轮 / 触控板滚动 | 以指针为中心缩放时间；水平滚动或 Shift+滚轮为平移 |
| 在价格轴上滚动滚轮，或 Alt+滚轮 | 缩放价格 |
| 捏合（触控板、双指） | 缩放 |
| 拖动价格轴 | 缩放价格（关闭自动缩放） |
| 拖动时间轴 | 改变 K 线间距 |
| 双击坐标轴 | 重置该轴（自动缩放、默认间距） |
| ← → / ↑ ↓ | 平移 10 % / 缩放 |
| Home / End | 跳到第一根 / 最新一根 K 线 |

十字光标跟随指针，并在坐标轴上显示价格和时间标签。其模式为 `Normal`、`Magnet`（吸附到该 K 线开盘价、最高价、最低价、收盘价中最近的一个）或 `Hidden`。

## 触屏

在触屏设备（手机、平板、触屏笔记本）上，手指没有悬停状态，因此手势与鼠标不同。触控笔的行为与鼠标相同。

| 触屏操作 | 效果 |
|---|---|
| 单指拖动 | 平移（移动中抬起：惯性滚动） |
| 双指操作 | 随双指距离的变化，以两指中点为中心缩放时间，并随中点移动而平移；抬起一根手指后，另一根手指可继续平移 |
| 单指保持不动 500 ms | 显示十字光标；它跟随手指移动而不平移图表，抬起后仍保留 |
| 轻点 | 触发点击；也会隐藏长按后保留的十字光标 |
| 双击坐标轴 | 重置该轴，与鼠标双击相同 |

- 手指需移动 8 CSS px 才会从按下变为拖动（鼠标为 3 px），因此轻微抖动的轻点仍算点击。
- 手指的命中范围更大：距线条 10 CSS px、距画线控制点 12 px、标记外扩 8 px。
- 正在绘制或拖动画线时，会忽略第二根手指。
- 十字光标模式为 `Hidden` 时，手指保持不动不会触发特殊操作；移动手指会平移图表。
- 系统接管触摸时（页面开始滚动、来电等），手势会结束，不触发点击或惯性滚动。

在浏览器中，竖向滑动是平移图表还是滚动页面，由 `touchScroll` 选项决定；见[触屏](web.md#touch-screens)。

## 事件

图表回报的内容（十字光标移动、点击、可见范围变化、历史数据请求、画线变更）见[十字光标与事件](crosshair-events.md)。在 Rust 中，用 `Chart::drain_events` 拉取相同的事件；如果一段时间内没有取走它们，较新的十字光标和范围事件会替换较旧的，而不会不断堆积。

## 时间

输入事件携带时间戳（`time_ms`），`build_frame` 接受当前时间（`now_ms`）；两者必须来自同一个时钟。惯性滚动和长按都会用到它们：当事件时间或帧时间达到按下后的 500 ms，保持不动的手指就会唤出十字光标。绑定层使用 `performance.now()`（Web）或随窗口启动的单调时钟（桌面）。
